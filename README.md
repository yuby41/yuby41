## 🚀 Featured Project

### Laravel Ollama Agent API

A local AI agent API built with **Laravel 12, PHP 8.3 and Ollama**.

The application implements a two-agent pipeline:

```text
Client
   ↓
Laravel REST API
   ↓
PlannerAgent
   ↓
Ollama / Local LLM
   ↓
Structured Plan
   ↓
WriterAgent
   ↓
Ollama / Local LLM
   ↓
Final Response
```

Key engineering aspects:

* Local LLM integration through Ollama
* Planner / Writer agent orchestration
* Structured JSON generation
* Dedicated LLM service layer
* Custom exception handling
* Laravel dependency injection
* PHPUnit unit and feature tests
* Mocked LLM communication for deterministic testing
* Continuous Integration with GitHub Actions
